## How a row is measured

Each row names the faults that measure it (build, blocks, fault type: stuck-at for a permanent λ, flips for a transient one -- v1's rows of type 'both' are split into the two parts). Each fault carries the campaign's weight (its block's bits / its block's sample), so a row spanning blocks is a bit-weighted estimate. F_safe = the weighted fraction masked (results bit-exact, no cause: a safe fault in this workload); DC_RF = detected / (detected + dangerous) (a hang without a cause is dangerous, one the watchdog or the fetch timeout caught is detected); the interval is Wilson's at Kish's effective sample size. λ_SPF/RF = λ x SR x FMD x SPF x (1 - F_safe) x (1 - DC_RF), so the residual is λ x the dangerous fraction. Two sensitivities: no credit for masked faults (F_safe = 0: every fault assumed to matter in some workload) and every measured row at the 95 % upper bound of its dangerous fraction (except a row a passing proof covers for every case -- the weight buffer's single flips, ecc39 -- when no fault of it was dangerous). Rows the campaign cannot measure keep v1's value and say why. Every cause was raised within the FTTI (10 ms = 20,000,000 cycles at 2 GHz; the longest run is a few thousand cycles).
